## 💻 Исходный код программы (`Program.cs`)

Программа намеренно написана предельно просто, без тяжелых математических уравнений:

```csharp
using System;

namespace _10_11
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("==========================================================");
            Console.WriteLine("  Практическая работа №10-11: Отладка программы в C#");
            Console.WriteLine("==========================================================\n");

            // 1. Итерационный цикл (для точек останова F9, окон Locals, Autos, Watch)
            int sum = 0;
            int multiplier = 2; // Переменная для изменения «на лету» в окне Watch

            Console.WriteLine("--- 1. Итерационный цикл ---");
            for (int i = 1; i <= 5; i++)
            {
                // Точка останова #1: клавиша F9 на этой строке
                int y = i * multiplier;
                sum += y;
                Console.WriteLine($"Шаг {i}: i = {i}, y = {y}, sum = {sum}");
            }

            // 2. Демонстрация изменения переменной в отладчике
            Console.WriteLine("\n--- 2. Проверка изменения переменной multiplier ---");
            if (multiplier > 10)
            {
                Console.WriteLine($"[УСПЕХ] Значение multiplier было изменено в отладчике на: {multiplier}!");
            }
            else
            {
                Console.WriteLine($"Обычный режим: значение multiplier = {multiplier}");
            }

            // 3. Обработка исключения (деление на ноль без сложных формул)
            Console.WriteLine("\n--- 3. Обработка исключения: деление на ноль ---");
            try
            {
                int a = 10;
                int b = 0; // делитель равен 0

                Console.WriteLine($"Попытка деления {a} на {b}...");
                int result = a / b; // здесь возникает исключение System.DivideByZeroException
                Console.WriteLine($"Результат: {result}");
            }
            catch (DivideByZeroException ex)
            {
                // Точка останова для перехвата исключения
                Console.WriteLine($"[Блок catch]: Ошибка! Деление на ноль невозможно ({ex.Message})");
            }
            finally
            {
                Console.WriteLine("[Блок finally]: Ресурсы освобождены, блок завершил работу.");
            }

            Console.WriteLine("\nПрограмма успешно завершена.");
        }
    }
}
```

## ❓ Ответы на контрольные вопросы

### 1. Что такое отладка?
**Отладка (debugging)** — это процесс обнаружения, локализации, анализа причин и устранения дефектов (багов, синтаксических и логических ошибок), нарушающих правильную работу программы.  
В отличие от тестирования (которое лишь констатирует факт сбоя — «что сломалось»), отладка отвечает на вопрос «почему и где именно в исходном коде произошел сбой» и устраняет обнаруженный дефект.

### 2. Какие инструменты отладки вам известны?
В среде Microsoft Visual Studio используются:
1. **Точки останова (Breakpoints):** обычные (`F9`), условные (*Conditional Breakpoints*) и по счетчику проходов (*Hit Count*).
2. **Команды пошагового выполнения:** `F10` (*Step Over*), `F11` (*Step Into*), `Shift+F11` (*Step Out*).
3. **Окна анализа данных:** `Autos`, `Locals`, `Watch 1–4`, `QuickWatch`.
4. **Интерактивные средства:** `Immediate Window` (командная строка вычисления выражений и изменения значений переменных), `DataTips` (всплывающие подсказки).
5. **Анализ стека и потоков:** `Call Stack` (цепочка вызовов функций).
6. **Контроль исключений:** `Exception Settings` (`Ctrl+Alt+E`) и `Exception Helper`.

### 3. Методы отладки
- **Интерактивная отладка в IDE:** точки останова, пошаговое выполнение и анализ памяти.
- **Логирование (Print Debugging):** вывод промежуточных значений через `Console.WriteLine` или лог-файлы.
- **Метод обратного прослеживания (дедукции):** движение от места проявления ошибки вверх по графу вызовов к первопричине.
- **Метод индукции:** выдвижение и проверка гипотез на основе сравнения успешных и ошибочных тестов.
- **Метод дихотомии (половинного деления):** сужение области поиска путем многократного деления подозрительного кода пополам.
- **Стресс-тестирование граничных значений:** проверка надежности блоков `try-catch` при передаче экстремальных данных (например, нулевой знаменатель).
