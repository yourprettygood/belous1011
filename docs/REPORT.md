## 💻 Исходный код программы (`Program.cs`)

Вся логика работы лаконично реализована в одном файле `Program.cs`:

```csharp
using System;

namespace _10_11
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("==========================================================");
            Console.WriteLine("  Практическая работа №10-11: Отладка программы в C#");
            Console.WriteLine("==========================================================\n");

            // 1. Итерационный цикл (для демонстрации Breakpoints, Locals, Autos, Watch)
            double sum = 0;
            int multiplier = 2; // Переменная для изменения «на лету» в окне Watch

            Console.WriteLine("--- 1. Итерационный расчет с контролем ошибок ---");
            for (int i = 1; i <= 5; i++)
            {
                try
                {
                    // Точка останова #1: клавиша F9 на этой строке
                    double y = Calculate(i);
                    sum += y * multiplier;
                    Console.WriteLine($"Шаг {i}: x = {i}, y = {y,6:F2}, sum = {sum,6:F2}");
                }
                catch (DivideByZeroException ex)
                {
                    // Точка останова для перехвата исключения
                    Console.WriteLine($"Шаг {i}: x = {i} -> [Ошибка]: {ex.Message}");
                }
            }

            // 2. Демонстрация изменения переменной в отладчике
            Console.WriteLine("\n--- 2. Проверка модификации переменной multiplier ---");
            if (multiplier > 10)
            {
                Console.WriteLine($"[УСПЕХ] Значение multiplier было изменено в отладчике: {multiplier}!");
            }
            else
            {
                Console.WriteLine($"Обычный режим: значение multiplier = {multiplier}");
            }

            // 3. Организация обработки исключений (try - catch - finally)
            Console.WriteLine("\n--- 3. Демонстрация блока try-catch-finally ---");
            try
            {
                Console.WriteLine("Вызов функции Calculate(3), приводящей к делению на 0...");
                double res = Calculate(3);
                Console.WriteLine($"Результат: {res}");
            }
            catch (DivideByZeroException ex)
            {
                Console.WriteLine($"[Блок catch]: Перехвачено исключение: {ex.Message}");
            }
            finally
            {
                Console.WriteLine("[Блок finally]: Ресурсы освобождены, блок завершил работу.");
            }

            Console.WriteLine("\nПрограмма успешно завершена.");
        }

        /// <summary>
        /// Простая функция: y = (x^2 + 4) / (x - 3)
        /// При x = 3 знаменатель обращается в 0, что вызывает исключение.
        /// </summary>
        static double Calculate(double x)
        {
            double numerator = x * x + 4;
            double denominator = x - 3;

            if (denominator == 0)
            {
                throw new DivideByZeroException("Знаменатель равен 0! Деление на ноль невозможно.");
            }

            return numerator / denominator;
        }
    }
}
```

## ❓ Ответы на контрольные вопросы

### 1. Что такое отладка?
**Отладка (debugging)** — это процесс обнаружения, локализации, анализа причин и устранения дефектов (багов, синтаксических и логических ошибок), нарушающих правильную работу программы.  
В отличие от тестирования (которое лишь выявляет факт наличия ошибки — «что не работает»), отладка отвечает на вопрос «почему и где именно в исходном коде произошел сбой» и устраняет обнаруженный дефект.

### 2. Какие инструменты отладки вам известны?
В среде Microsoft Visual Studio используются:
1. **Точки останова (Breakpoints):** безусловные (`F9`), условные (*Conditional Breakpoints*) и по счетчику проходов (*Hit Count*).
2. **Команды пошагового выполнения:** `F10` (*Step Over*), `F11` (*Step Into*), `Shift+F11` (*Step Out*).
3. **Окна анализа данных:** `Autos`, `Locals`, `Watch 1–4`, `QuickWatch`.
4. **Интерактивные средства:** `Immediate Window` (командная строка вычисления выражений и изменения значений переменных), `DataTips` (подсказки при наведении).
5. **Анализ стека и потоков:** `Call Stack` (цепочка вызовов функций).
6. **Контроль исключений:** `Exception Settings` (`Ctrl+Alt+E`) и `Exception Helper`.

### 3. Методы отладки
- **Интерактивная отладка в IDE:** точки останова, пошаговое выполнение и анализ памяти.
- **Логирование (Print Debugging):** вывод промежуточных значений через `Console.WriteLine` или лог-файлы.
- **Метод обратного прослеживания (дедукции):** анализ от места проявления ошибки вверх по графу вызовов к первопричине.
- **Метод индукции:** выдвижение и проверка гипотез на основе сравнения успешных и ошибочных тестов.
- **Метод дихотомии (половинного деления):** сужение области поиска путем многократного деления подозрительного кода пополам.
- **Стресс-тестирование граничных значений:** проверка надежности блоков `try-catch` при передаче экстремальных данных (например, нулевой знаменатель).
